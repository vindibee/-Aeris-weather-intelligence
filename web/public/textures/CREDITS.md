# Текстуры Земли

Файлы `earth_atmos_2048.jpg`, `earth_normal_2048.jpg`, `earth_specular_2048.jpg`
взяты из набора примеров three.js (`examples/textures/planets`), репозиторий
mrdoob/three.js под лицензией MIT.

Исходные данные — снимки NASA Visible Earth / Blue Marble, находящиеся в
общественном достоянии (public domain).

- three.js: https://github.com/mrdoob/three.js
- NASA Visible Earth: https://visibleearth.nasa.gov/collection/1484/blue-marble
