# Telegram-бот Aeris

## Запуск

```bash
pip install -r bot/requirements.txt
cp bot/.env.example bot/.env      # вписать TELEGRAM_BOT_TOKEN и BOT_API_SECRET
python -m bot.main
```

Боту нужен работающий API сайта (`npm run dev:api` или `npm start`).

## Что умеет

**Онбординг.** `/start` → выбор языка инлайн-кнопками (UK, RU, EN, DE, FR, ES) →
приветствие → главное меню из двух кнопок.

**Обычные функции (бесплатно)**
- «Войти на сайте» — бот просит у API одноразовый код и присылает ссылку;
  переход по ней авторизует в браузере без пароля.
- «Погода сейчас» — принимает название города или геолокацию, отдаёт текущую
  сводку и рекомендацию по одежде. Если города нет — показывает подсказки.

**Премиум функции (платно)**
- Оплата Telegram Stars (валюта XTR) или Crypto Pay (USDT).
- После оплаты открывается планировщик: город + до трёх времён рассылки.
  APScheduler шлёт подробную сводку с рекомендацией по одежде в часовом поясе
  выбранного города.

## Переменные окружения

См. `.env.example`. Обязательны только `TELEGRAM_BOT_TOKEN` и, для кнопки
входа на сайте, `BOT_API_SECRET` — тот же, что в `server/.env`.

Криптоплатежи включаются наличием `CRYPTO_PAY_TOKEN`: без него кнопка не
показывается, остальной бот работает.
